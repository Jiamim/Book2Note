## 内容如何使用

详细笔记用于理解，速查用于复习与选择下一步；不要只按速查的数字执行而略过条件。每章可独立阅读，交叉链接用于补充。读完后先闭书回答复习问题，再对照自测参考要点，最后用一个新情境检验能否选择并解释方法。

研究结果、实践建议与个人经验分别说明。睡眠药物、补剂、冷刺激、皮肤日晒、红光眼部干预和创伤处理有各自的证据与适用条件。
