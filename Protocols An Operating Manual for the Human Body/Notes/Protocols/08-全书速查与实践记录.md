## 二、普通生活方案的时间速查

| 方案 | 常见建议范围 | 执行条件 |
| --- | --- | --- |
| 晨间户外光 | 醒后第一小时；晴天约 5—10、阴天约 15—20、厚阴云约 30 分钟或更久 | 建议起点有差异，需结合光照条件；不直视太阳 |
| 傍晚户外光 | 通常 10—15 分钟，可在约 5—30 分钟范围内按条件安排 | 结合自然日光，而非临睡前强光灯 |
| 睡前降光、减少屏幕 | 至少最后约 1 小时 | 夜醒仍保留暗而安全的环境 |
| 作息一致 | 每周 6—7 天，约 ±30 分钟 | 保留足够睡眠，不为一致而持续少睡 |
| 午睡 | 日常多为 15—20 分钟；明显缺觉或特定情境另考虑较长午睡 | 学习前恢复常选约 30 分钟以内，按目的与夜睡反应理解 |
| NSDR | 约 10—30 分钟 | 安静安全，作为恢复，不换算成睡眠小时 |
| 咖啡因截止 | 睡前约 8—10 小时，敏感者更早 | 同时观察总量和夜间睡眠 |
| 步行 | 饭后 5—10 分钟，久坐间穿插走动 | 从当前能力增加，不硬凑步数 |
| 抗阻训练 | 每周 3 次；每次约 60 ±20 分钟 | 学动作、记录、匹配恢复 |
| 心肺训练 | 每周长、低强度；中等；短、高强度各一次 | 不把各类时长或例子全部叠加 |
| 活动度 | 每周 2—4 次，每次约 10 分钟 | 无痛、缓慢进阶 |
| 生理叹息 | 按需要 1—3 次 | 不反复过度换气 |
| 微冥想 | 每日约 5 分钟，或从十次呼吸开始 | 练发现走神并回来，不以消灭念头为目标 |
| WOOP | 初次约 10 分钟，之后按需更新 | 计划必须是具体“如果—那么”行动 |
| 学习微休息 | 动作练习约 5—30 秒；认知任务可尝试约 5—10 分钟 | 按任务与疲劳调整；恢复精神与提升复杂任务表现不同 |
| 学后自测 | 约 1—5 分钟 | 不看答案先提取，然后核对 |
| 感恩或独处 | 短至几分钟 | 真诚、具体、有空间，不作为强迫任务 |
| 表达性写作 | 连续四天，每天约 15—20 分钟 | 围绕相关旧经历；到时停止，之后留恢复时间，明显恶化时暂停 |

## 四、核心术语表

| 术语 | 中文与作用 |
| --- | --- |
| SCN | 视交叉上核，协调昼夜节律的主时钟 |
| ipRGC | 内在光敏视网膜神经节细胞，把光信息送往非成像视觉通路等 |
| melanopsin | 黑视素，相关感光色素 |
| chronotype | 睡眠时间偏好／睡眠类型，有生物与环境影响 |
| adenosine | 腺苷，参与清醒后睡眠压力的形成 |
| HPA axis | 下丘脑—垂体—肾上腺轴，参与皮质醇等的调节；不能把肾上腺所有反应都归为同一机制 |
| catecholamines | 儿茶酚胺，包括多巴胺、去甲肾上腺素和肾上腺素，作用依位置与情境而异 |
| SNS / PNS | 交感／副交感神经系统，共同调节自主功能 |
| NSDR | 非睡眠深度休息，Huberman 命名的自我引导放松框架 |
| N1 / N2 / N3 / REM | 睡眠阶段；N3 是慢波深睡，REM 是快速眼动睡眠 |
| sleep efficiency | 睡眠效率，实际总睡眠时间占卧床时间的比例；不按完成周期数定义 |
| α / β diversity | 菌群样本内部多样性／样本间群落组成差异，不能混成一个“肠菌多少”的指标 |
| glymphatic clearance | 类淋巴清除，脑内代谢清理研究中的概念，不是个人设备能够直接精确测量的“排毒分数” |
| compound / isolation | 复合／孤立动作，按多关节或较集中肌群功能区分 |
| progressive overload | 渐进超负荷，挑战随能力提高而增加 |
| HRV | 心率变异性，描述心搏间隔变化，不等于平均心率，也不把单一数字视为心理压力诊断 |
| failure / RIR | 力竭／剩余可完成次数，用于表达一组的努力程度与余力 |
| BMR / TDEE | 基础代谢／每天总能量消耗，不能混为同一个热量目标 |
| NEAT | 非运动性活动产热，日常走动等活动的能量消耗 |
| VO₂max | 最大摄氧量，综合氧摄取、输送与使用能力的指标 |
| BDNF | 脑源性神经营养因子，与神经系统适应研究相关 |
| CP:C | 完整蛋白与热量比例指标，主要帮助比较蛋白密度 |
| leucine / mTOR | 亮氨酸／细胞生长与营养感知相关调节因子，连接营养、组织合成与恢复研究 |
| EPA / DHA | 不同 omega-3 脂肪酸，不能与鱼油总重量互换 |
| photobiomodulation | 光生物调节，特定波长与剂量下组织反应的干预领域 |
| SDAP | 自主引导的适应性可塑性，一种自主学习流程框架 |
| WOOP | 愿望、结果、障碍、计划，心理对照的执行结构 |
| aMCC | 前中扣带皮层，与努力意愿等研究相关；WOOP 改变它的说法尚属推测 |
| CAR | 皮质醇觉醒反应，与昼夜节律相关，但不能简化成醒来只由一种激素决定 |
| attractor state | 吸引子状态，用于解释某种思考模式如何持续占据注意，影响任务切换 |
| DMN | 默认模式网络，参与自我相关思维等，不是应永久关闭的坏网络 |
| AMPK / PGC-1α | 步行与肌肉收缩代谢解释中的调节分子，与特定刺激及研究条件相关 |
| optic flow | 光流，移动时环境影像相对流动；与户外步行及状态变化的解释相关 |
| ACTH / CRH / PVN | 促肾上腺皮质激素／促肾上腺皮质激素释放激素／室旁核，用来理解 HPA 信号层级 |
| schema | 图式，抽取多次经验中共同结构，帮助理解与提取；睡眠与图式形成有关 |
| proprioception | 本体感觉，身体位置与动作的感觉信息，配合外部反馈帮助调整技能 |
| leptin | 瘦素，由脂肪组织参与传递能量储备信息，与一餐脂肪或体脂量不能简单等同 |
| DAO | 二胺氧化酶，Huberman 的发酵食品耐受经验中提及的工具，不是自动诊断组胺问题的依据 |

## 六、复习的验收方式

读完每章后，不看笔记回答三个问题：这一章的机制主线是什么？怎样给一个具体情境选择方法？哪些参数或结论不能机械推广？

回答后对照各章的自测参考要点，补回漏掉的条件，再尝试一个不同于正文的情境。这样既检查记忆，也检查能否迁移。

### 按主题检验掌握

| 主题 | 应能独立完成的任务 | 常见理解缺口 |
| --- | --- | --- |
| 睡眠 | 解释节律与睡眠压力，分析日光、咖啡因、午睡如何共同影响一晚睡眠 | 只背睡眠时长或补剂清单，忽略时间与适用条件 |
| 运动 | 给出兼顾力量、心肺与活动度的周安排，分清热身、工作组、努力程度与恢复 | 把组数、酸痛或单次极限当作唯一效果指标 |
| 压力控制 | 区分当场调节与平时承受能力训练，并说明为何选某个工具 | 不管情境都追求更放松，或把更强刺激当成更有效 |
| 营养 | 分清能量、蛋白密度与营养质量，解释一餐与全天、鱼油与 EPA 的计量差别 | 只按饮食名称判断，或把不同用量重复相加 |
| 光照 | 区分校时、皮肤反应与设备干预，说明时间、波长、剂量和研究指标 | 把不同组织的结果合成全身收益，忽略眼部及 UV 条件 |
| 学习 | 用 SDAP 与 WOOP 组织一次练习，包含真实尝试、反馈、休息、自测与再次应用 | 把兴奋、熟悉感或神经重放倍数当成学习成绩 |
| 个人成长 | 区分当下参与、角色行动、内在更新、旧痛点写作与失去后的预期调整 | 用更忙碌替代理解感受，或要求自己消灭所有负面情绪 |

### 一次完整的自测示例

**情境示例：** 一个人白天困倦，午后睡很久，傍晚喝咖啡，晚上靠红光面板和继续刷手机等待入睡；他认为这也能提高次日学习能力。

不看笔记，尝试回答：

1. 这套安排分别影响了哪些过程？
2. 哪些判断需要知道个人作息、咖啡因量、午睡时长或设备条件？
3. 哪个普通生活变量适合先观察？
4. 为什么更清醒或一个设备指标变化，不能证明次日学得更好？

**参考思路：** 长午睡可能降低夜间睡眠压力，咖啡因会阻断困倦信号，灯光和信息输入可能继续提高唤醒。红光设备的某项研究结果不等于获得完整睡眠，也不保证学习巩固。先明确真实问题并记录作息，从可持续的一项基础行为开始观察；学习效果还要用稍后的闭书提取与应用检验。不能由这段简短描述直接诊断病因或制定个人用药、设备方案。

解释清楚并不等于动作技术或健康问题已经解决。涉及具体训练动作，还要用真实操作与反馈验证；涉及持续症状、用药或设备治疗，需要相应专业判断。
