# 《Protocols》HTML 读书分享

共 50 页，七章均包含概念、方法、研究例子和适用条件。默认“25–30 分钟分享”路线包含 35 页；切换“完整阅读”可查看另外 15 页的方法、研究和问答。每页附讲解备注，完整分章笔记也已内置。

## 打开演示

先运行下方生成命令，再在 Chrome、Edge 或 Safari 打开 `Protocols-读书分享.html`。图片、样式、控制代码和完整分章笔记已内置，可以单独发送该文件并离线使用。外部研究链接需要网络。

生成的 `index.html` 是分文件版本，必须与 `theme.css`、`presentation.js` 和 `assets` 一起保留。分文件版的笔记链接依赖工程中的 `Notes` 目录。

## 演示操作

| 操作 | 方法 |
| --- | --- |
| 切换路线 | 底部选择“25–30 分钟分享”或“完整阅读 · 50 页” |
| 翻页 | 左右方向键、空格或底部按钮 |
| 目录 | 按 O，或点击“目录” |
| 跳转 | 底部直接输入页码，或使用地址中的 `#slide-18` |
| 演讲备注 | 按 N，或点击“备注” |
| 独立演讲者窗口 | 按 P，或点击“演讲者”，两个窗口翻页同步 |
| 全屏 | 按 F，或点击“全屏” |
| 暂时黑屏 | 按 B，再按 B 或点击恢复 |
| 手机阅读 | 竖屏逐页阅读，左右滑动或底部按钮翻页 |
| 快捷键 | 按 ? |
| 阅读笔记 | 点击底部“读书笔记”或按 L，也可点击备注中的笔记链接 |

投屏时，主窗口只展示幻灯片，独立演讲者窗口显示备注和计时器。浏览器如拦截新窗口，可先在本页打开备注。讲稿供参考，可按个人语速和现场讨论调整。

## 打印为 PDF

点击“打印”，在浏览器打印窗口选择“另存为 PDF”。版式按 16:9 横版分页；若浏览器不采用页面尺寸，选择横向、无页边距，并开启背景图形、关闭页眉页脚。按当前路线打印 35 页或 50 页，演讲备注不随幻灯片打印。

## 修改与重新生成

文案和逐页讲解保存在 `deck_content.py`，页面结构保存在 `template.html`，由 `build_deck.py` 生成 `index.html`。请修改源文件后重新生成，避免直接修改导出文件。样式在 `theme.css`，交互在 `presentation.js`。笔记来自 `Notes/Protocols`。

修改后执行：

```bash
python3 -B Presentations/Protocols/build_deck.py
python3 -B Presentations/Protocols/build_portable.py
```

生成过程仅使用 Python 标准库，将页面资源与笔记打包到便携 HTML。演示本身无第三方脚本或字体依赖。

## 内容与素材

演示涵盖七个主题的机制、方法和应用。实践建议、分享者示例和研究限制分别说明。详细健康参数在备注或分章笔记中，主体不会逐项展示补剂用量。

封面使用自制 SVG 排版。日光、训练、书写照片来自 Unsplash，来源与许可见 [第三方素材说明](../../THIRD_PARTY_NOTICES.md)，原图地址也保留在对应页备注。照片用于表现生活场景，不作为动作教学或实验结果。

导出的两个 HTML 文件不纳入源码管理，可按需生成或作为发布附件。
